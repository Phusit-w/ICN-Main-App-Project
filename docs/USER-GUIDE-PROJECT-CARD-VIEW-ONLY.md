# คู่มือการใช้งานระบบค้นหาโครงการ (Project Card)

สำหรับผู้ใช้งานสิทธิ์ **ดูอย่างเดียว**

เวอร์ชันเอกสาร: 6 ตุลาคม 2026

## 1. วัตถุประสงค์

ระบบค้นหาโครงการใช้สำหรับค้นหาและดูข้อมูลโครงการของบริษัทจากเอกสารสัญญาและหนังสือรับรองผลงานที่จัดเก็บในคลังไฟล์ PS ผู้ใช้สิทธิ์ดูอย่างเดียวสามารถ:

- ค้นหาโครงการด้วยรหัสโครงการ ชื่อลูกค้า ชื่อโครงการ หรือคำอธิบาย
- กรองโครงการตามลูกค้า ปี หมวดหมู่ ลักษณะงาน และงบประมาณ
- เรียงลำดับรายการตามโครงการ ลูกค้า ปี หรืองบประมาณ
- เปิดดูรายละเอียดโครงการและสถานะการยืนยันงบประมาณ
- คัดลอกตำแหน่งไฟล์ เพื่อเปิดเอกสารต้นฉบับจาก PS share

ผู้ใช้สิทธิ์ดูอย่างเดียว **ไม่สามารถแก้ไขข้อมูลหรือยืนยันงบประมาณได้**

## 2. สิ่งที่ต้องมีก่อนเข้าใช้งาน

1. เครื่องคอมพิวเตอร์เชื่อมต่อเครือข่ายของบริษัท หรือเชื่อมต่อ VPN ของบริษัทแล้ว
2. มี Username และรหัสผ่านที่ได้รับจากผู้ดูแลระบบ
3. บัญชีได้รับสิทธิ์ **ค้นหาโครงการ · ดู**
4. ใช้เว็บเบราว์เซอร์ที่บริษัทอนุญาต เช่น Google Chrome หรือ Microsoft Edge

## 3. เข้าเว็บไซต์และเข้าสู่ระบบ

1. เปิดเว็บเบราว์เซอร์
2. พิมพ์ที่อยู่ต่อไปนี้ในช่อง Address แล้วกด Enter:

   `https://psaidemo.icn21.local`

3. ที่หน้าเข้าสู่ระบบ กรอกข้อมูล:

   - **Username**: ชื่อผู้ใช้ที่ได้รับจากผู้ดูแลระบบ
   - **Password**: รหัสผ่านของบัญชี

4. กดปุ่ม **เข้าสู่ระบบ**

หากลืมรหัสผ่าน ให้ติดต่อฝ่าย IT หรือผู้ดูแลระบบ ไม่ควรใช้บัญชีของผู้อื่นร่วมกัน

### การเข้าใช้งานครั้งแรก

หากเป็นการเข้าสู่ระบบครั้งแรก หรือผู้ดูแลระบบเพิ่งรีเซ็ตรหัสผ่าน ระบบจะเปิดหน้า **ตั้งรหัสผ่านใหม่** โดยอัตโนมัติ:

1. กรอกรหัสผ่านปัจจุบันที่ได้รับจากผู้ดูแลระบบ
2. ตั้งรหัสผ่านใหม่ ความยาวอย่างน้อย 10 ตัว และต้องมีตัวอักษรกับตัวเลข
3. กรอกรหัสผ่านใหม่ซ้ำในช่องยืนยัน
4. กด **เปลี่ยนรหัสผ่าน**

เมื่อเปลี่ยนสำเร็จ ระบบจะเปิดหน้าหลักของ ICN Apps

## 4. เปิดระบบค้นหาโครงการ

หลังเข้าสู่ระบบแล้ว สามารถเปิด Project Card ได้สองวิธี:

### วิธีที่ 1: จากหน้าหลัก

1. ที่หน้า **แอปพลิเคชัน** มองหาการ์ด **ค้นหาโครงการ**
2. กด **เปิดเครื่องมือ →**

### วิธีที่ 2: จากเมนูด้านซ้าย

1. กดเมนู **ค้นหาโครงการ**
2. ระบบจะเปิดหน้า Project Card ทันที

บัญชีที่ได้รับเฉพาะสิทธิ์ดู Project Card จะไม่เห็นเมนูของระบบอื่นที่ไม่ได้รับสิทธิ์ และจะไม่เห็น Admin Center

## 5. ภาพรวมหน้าค้นหาโครงการ

ด้านบนของหน้าจอเป็นช่องค้นหาและตัวกรอง ส่วนด้านล่างเป็นรายการโครงการ โดยแต่ละรายการแสดงข้อมูลสำคัญ เช่น:

- ชื่อโครงการและ Project Code
- หมวดหมู่หลักและหมวดหมู่รอง
- ลูกค้า
- ปีที่ลงนามสัญญา
- งบประมาณและสถานะการยืนยัน

ข้อความ **พบ … โครงการ** แสดงจำนวนโครงการที่ตรงกับเงื่อนไขปัจจุบัน

## 6. การค้นหาแบบทั่วไป

1. คลิกช่อง **ค้นหา**
2. พิมพ์คำที่ต้องการ เช่น:

   - Project Code: `PEA017`
   - ลูกค้า: `MEA`
   - เทคโนโลยีหรือคำในรายละเอียด: `Fiber`, `Teleprotection`, `RFID`
   - คำภาษาไทยจากชื่อหรือคำอธิบายโครงการ

3. กดปุ่ม **ค้นหา** หรือกด Enter
4. ตรวจสอบจำนวนและรายการโครงการที่พบ

การค้นหาจะตรวจ Project Code ลูกค้า ชื่อโครงการ คำอธิบาย หมวดหมู่ และลักษณะงานที่เกี่ยวข้อง

## 7. การกรองผลลัพธ์

สามารถใช้หลายเงื่อนไขพร้อมกันได้ ระบบจะแสดงเฉพาะโครงการที่ตรงกับทุกเงื่อนไขที่ระบุ

### ลูกค้า

เลือกหรือพิมพ์รหัสลูกค้า เช่น `PEA`, `MEA`, `NT` หรือ `EGAT`

กรณีเป็นงานรับเหมาช่วง ลูกค้าอาจแสดงในรูปแบบ `PEA (BBTEC)` โดยสามารถค้นหาจากชื่อเจ้าของโครงการหรือผู้รับเหมาหลักได้

### ช่วงปี

- **ตั้งแต่ปี**: ปีเริ่มต้น
- **ถึงปี**: ปีสิ้นสุด

ปีในระบบเป็นปีคริสต์ศักราช และหมายถึงปีที่ลงนามสัญญา ไม่ใช่ปีส่งมอบงาน

### ช่วงงบประมาณ

- **งบมากกว่า (ล้านบาท)**
- **งบน้อยกว่า (ล้านบาท)**

กรอกเป็นหน่วยล้านบาท เช่น `10` หมายถึง 10,000,000 บาท

### หมวดหมู่

ใช้กรองตามกลุ่มเทคโนโลยี เช่น:

- Fiber Optic
- IP Network
- Transmission
- Microwave & Radio
- Teleprotection

ผลลัพธ์รวมโครงการที่มีหมวดหมู่นั้นเป็นหมวดหมู่หลักหรือหมวดหมู่รอง

### ลักษณะงาน

ใช้กรองตามรูปแบบงานที่บริษัทส่งมอบ เช่น Supply, Installation, MA, Rental หรือ System Development

### ล้างเงื่อนไข

กด **ล้างค่า** เพื่อยกเลิกคำค้นหาและตัวกรองทั้งหมด แล้วกลับมาแสดงโครงการทั้งหมด

## 8. การเรียงลำดับรายการ

กดชื่อหัวคอลัมน์เพื่อเรียงรายการ ได้แก่:

- **โครงการ**
- **ลูกค้า**
- **ปี**
- **งบประมาณ (บาท)**

กดหัวคอลัมน์เดิมซ้ำเพื่อสลับระหว่างเรียงจากน้อยไปมากและมากไปน้อย สัญลักษณ์ลูกศรข้างชื่อคอลัมน์แสดงทิศทางการเรียงปัจจุบัน

## 9. เปิดดูรายละเอียดโครงการ

1. คลิกรายการโครงการที่ต้องการ
2. ระบบจะแสดงหน้าต่างรายละเอียด ซึ่งอาจประกอบด้วย:

   - Project Code และชื่อโครงการ
   - ลูกค้าและปีสัญญา
   - งบประมาณ แหล่งที่มาของงบ และ VAT
   - สถานะ **ยืนยันแล้ว** หรือ **ยังไม่ยืนยัน**
   - หมวดหมู่หลัก หมวดหมู่รอง และลักษณะงาน
   - คำอธิบายภาษาไทยและภาษาอังกฤษ
   - แหล่งที่มาของคำอธิบาย
   - หมายเหตุ
   - ตำแหน่ง Project Folder, สัญญา และหนังสือรับรอง

3. กด **ปิด** เพื่อกลับไปยังรายการ

บัญชีแบบดูอย่างเดียวจะไม่มีปุ่ม **แก้ไข** และไม่มีปุ่ม **ยืนยันงบประมาณ**

## 10. การอ่านสถานะงบประมาณ

- **ยืนยันแล้ว**: มีผู้ใช้สิทธิ์แก้ไขตรวจสอบและยืนยันตัวเลขแล้ว
- **ยังไม่ยืนยัน**: ตัวเลขยังไม่ได้รับการยืนยันจากผู้ใช้ แม้ระบบจะแสดงจำนวนเงินก็ตาม
- เครื่องหมาย `-`: ยังไม่มีตัวเลขงบประมาณในข้อมูลของโครงการนั้น

เมื่อนำข้อมูลไปใช้อ้างอิง ควรตรวจสอบสถานะทุกครั้ง หากยังไม่ยืนยันและต้องใช้ข้อมูลทางการ ให้เปิดเอกสารต้นฉบับหรือติดต่อผู้รับผิดชอบ

## 11. เปิดไฟล์ต้นฉบับจาก PS share

ในรายละเอียดโครงการ อาจมีตำแหน่งไฟล์สูงสุดสามประเภท:

- **โฟลเดอร์โครงการ**
- **สัญญา**
- **หนังสือรับรอง**

วิธีเปิดไฟล์:

1. กดปุ่ม **คัดลอก** ข้างตำแหน่งที่ต้องการ
2. เปิด Windows File Explorer
3. คลิกช่อง Address ด้านบน
4. วางตำแหน่งที่คัดลอก แล้วกด Enter

หากตำแหน่งใดแสดง `-` หรือไม่ปรากฏ หมายถึงระบบยังไม่มีตำแหน่งไฟล์ประเภทนั้น ไม่ได้หมายความว่าไฟล์ถูกลบ

การเปิด PS share ต้องเชื่อมต่อเครือข่ายบริษัทหรือ VPN และบัญชี Windows ต้องมีสิทธิ์เข้าถึงโฟลเดอร์นั้น

## 12. ออกจากระบบ

เมื่อใช้งานเสร็จ โดยเฉพาะบนเครื่องที่มีผู้ใช้งานร่วมกัน:

1. กด **ออกจากระบบ** ที่เมนูด้านซ้าย
2. ตรวจสอบว่าระบบกลับไปหน้าเข้าสู่ระบบแล้ว

## 13. ปัญหาที่พบบ่อย

### เปิดเว็บไซต์ไม่ได้

- ตรวจสอบว่าเชื่อมต่อเครือข่ายบริษัทหรือ VPN แล้ว
- ตรวจสอบว่าพิมพ์ `https://psaidemo.icn21.local` ถูกต้อง
- หากยังเข้าไม่ได้ ให้แจ้งฝ่าย IT พร้อมข้อความผิดพลาดหรือภาพหน้าจอ

### เข้าสู่ระบบไม่ได้

- ตรวจสอบ Username และรหัสผ่าน รวมถึงภาษาแป้นพิมพ์และ Caps Lock
- หากลืมรหัสผ่านหรือบัญชีถูกปิด ให้ติดต่อผู้ดูแลระบบ

### ไม่พบเมนูค้นหาโครงการ

บัญชีอาจยังไม่ได้รับสิทธิ์ **ค้นหาโครงการ · ดู** ให้ติดต่อผู้ดูแลระบบเพื่อตรวจสอบสิทธิ์

### ค้นหาแล้วไม่พบข้อมูล

- ลองใช้ Project Code หรือคำค้นหาที่สั้นลง
- ตรวจสอบตัวกรองลูกค้า ปี งบประมาณ หมวดหมู่ และลักษณะงาน
- กด **ล้างค่า** แล้วค้นหาใหม่
- โครงการต้องอยู่ในแหล่งข้อมูล Contract หรือ Work Certificate ภายใต้ `_BID` จึงจะมี Project Card

### เปิดตำแหน่งไฟล์ไม่ได้

- ตรวจสอบการเชื่อมต่อเครือข่ายบริษัทหรือ VPN
- ตรวจสอบว่าคัดลอกตำแหน่งครบถ้วน
- หากระบบแจ้งไม่มีสิทธิ์ ให้ติดต่อผู้ดูแล PS share หรือฝ่าย IT

## 14. ขอบเขตสิทธิ์ของผู้ใช้ดูอย่างเดียว

| ทำได้ | ทำไม่ได้ |
| --- | --- |
| ค้นหาและกรองโครงการ | แก้ไขรายละเอียดโครงการ |
| เรียงลำดับรายการ | เปลี่ยน Category, Tags หรือ Work Types |
| ดูรายละเอียดและงบประมาณ | เปลี่ยนงบประมาณหรือสถานะ VAT |
| ดูสถานะการยืนยันงบ | ยืนยันงบประมาณ |
| คัดลอกตำแหน่งไฟล์ | จัดการผู้ใช้หรือหมวดหมู่ระบบ |

หากต้องการแก้ไขข้อมูล ให้แจ้งผู้ใช้ที่มีสิทธิ์ **ค้นหาโครงการ · ดูและแก้ไข** หรือผู้ดูแลระบบ พร้อมระบุ Project Code และข้อมูลที่ต้องการแก้ไข
